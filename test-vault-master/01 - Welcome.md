# Welcome to Custom Note Width

This vault demonstrates every feature of the **Custom Note Width** plugin. Open notes in order to see each capability in action.

## What this plugin does

Controls the line width of each note individually — via slider, text input, preset pills, YAML frontmatter or commands.

## Demo path

1. **This note** — default width (no YAML), applies the global default
2. **02 – Narrow (30%)** — YAML width matches a pill preset
3. **03 – Standard (50%)** — YAML width matches another preset
4. **04 – Wide (100%)** — YAML width matches the third preset
5. **05 – Custom (42%)** — YAML width matches no preset (no pill active)
6. **06 – Code Blocks** — separate width for fenced code blocks

## Try this

- Open **Settings → Custom Note Width → Control mode** and switch between *Slider* and *Pills*
- In Pills mode you get three configurable preset buttons in the status bar
- Bind hotkeys via **Settings → Hotkeys** (filter: *Custom Note Width*)
